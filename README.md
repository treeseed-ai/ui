# TreeSeed Cordis UI contracts

Task 3C owner: https://github.com/treeseed-ai/ui/issues/80. This first review slice owns renderer-neutral view, action, contribution and hydration contracts plus semantic consumer enforcement. Subsequent independent candidates add pure React class components and selected native Cordis renderers, then browser/Astro qualification. The original Astro components remain unchanged in the original repository checkout.

`@treeseed-cordis/ui/contracts` exports strict executable schemas, inferred types, typed component/theme tokens and class-compatible contracts. `UiContribution` binds contribution/component IDs, selected provider, the actual model-schema projection digest and immutable stylesheet digest. Hydration carries safe view/action/contribution/asset identities; it carries no executable callbacks, principal services, sessions or credentials. Identity remains the owner of Keycloak authority; consuming hosts retain session/token custody and authorization.

Every visual implementation in the subsequent candidates must be mobile-first from 320 CSS pixels through widescreen: 320/375/768/1024/1440/1920/2560, 200% text sizing, long content, keyboard, at least 44×44 authored controls and no page overflow. Labeled semantic-table local overflow is permitted. Astro consumes React TSX classes; native mobile/Electron remain future qualification.

Consumers run `UiSourcePolicy.check(root)` from `./source-policy`. Its TypeScript AST checks reject intrinsic JSX markup, DOM construction/HTML sinks, CSS imports, inline HTML templates, direct React DOM renderer imports and Astro component implementations. Text-content/style mutations and aliased React DOM construction are covered by negative fixtures too. Domain view models/action classes and UI component imports remain consumer-owned. SDK source policy separately enforces strict TypeScript classes and owner imports. This library is the presentation owner; no parallel renderer or second dependency container is authorized.

Run `bun install --frozen-lockfile --ignore-scripts` and `bun run verify`. Verification includes strict check/build and nonempty unit/integration/built-program tiers. The portable contract program imports the public package without DOM/Node renderer initialization. All issues, including Platform #678, remain open until authorized release; no production publication or activation occurs here.

## Selected React/server/terminal providers

This second review slice adds six pure React TSX class components (text, status, table, form, navigation, feedback), a UI-owned responsive stylesheet and selected native Cordis component/theme/renderer services. `./react`, `./providers`, `./styles`, `./server` and `./terminal` are public exports. Browser roots and Astro qualification arrive in the next dependent candidate.

`UiServerRenderer.create(configuration)` and `UiTerminalRenderer.create(configuration)` own independent native presentation scopes. Call `render(view)` and await `dispose()`. Same-contract alternatives are selected through native provider metadata; the facade never selects a concrete implementation directly. UI's typed `ui.presentation` collection projects the explicit component/theme bindings through the SDK locator without caching provider instances. Native leases and effects own cleanup.

`RenderedPage` includes escaped HTML, contribution identity, immutable stylesheet references, shared presentation generation and the full renderer-root generation. Presentation identity binds selected component/theme configuration and artifacts, independent of request scope labels or unselected alternatives. `styles()` returns exact CSS bytes/digest/path for the host. Server pages use external same-origin CSS; inline-CSP exceptions are unnecessary. Contributions bind the actual class model-schema projection and selected native provider, not a separate hand-written schema list.

The reusable components own logical/fluid sizing, local semantic-table overflow, 44px authored controls and reduced-motion/focus styling. All seven widths, 200% text and actual browser interaction are mandatory gates in the dependent browser candidate. This server/terminal slice qualifies default construction, escaping, semantic boundaries, provider substitution and closed-scope rejection; it makes no browser hydration claim by itself.
